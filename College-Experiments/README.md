# Artificial Neural Network (ANN) Experiments

This repository contains a collection of experiments implemented as part of the **Artificial Neural Networks** laboratory course. Each experiment demonstrates different neural network models, architectures, and learning algorithms using Python and TensorFlow.

---

## 📂 List of Experiments

1. **ANN_1_Plot**  
   Introduction to plotting and visualizing data for ANN applications.  

2. **ANN_2_McCulloch_Pitts**  
   Implementation of the McCulloch-Pitts neuron model (basic building block of ANNs).  

3. **ANN_3_Perceptron**  
   Single-layer perceptron model for binary classification tasks.  

4. **ANN_4_Perceptron Learning**  
   Training a perceptron using the perceptron learning rule.  

5. **ANN_5_Bidirectional Associative Memory (BAM)**  
   Implementation of BAM for pattern association tasks.  

6. **ANN_6_TensorFlow Recognize Numbers**  
   Handwritten digit recognition using TensorFlow (likely on the MNIST dataset).  

7. **ANN_7_Back Propagation Network**  
   Implementation of a simple backpropagation neural network.  

8. **ANN_8_ART Neural Network**  
   Adaptive Resonance Theory (ART) neural network implementation.  

9. **ANN_9_Back Propagation Feed-forward Neural Network**  
   Feed-forward neural network with backpropagation learning.  

10. **ANN_10_Hopfield Network**  
   Implementation of Hopfield recurrent neural network for associative memory.  

11. **ANN_11_Logistic Regression using TensorFlow**  
   Logistic regression classifier implemented with TensorFlow.  

12. **ANN_12_TensorFlow Implementation of CNN**  
   Convolutional Neural Network (CNN) implementation using TensorFlow for image recognition tasks.
